What this screen proposes
  1. Name is shown surname first and sorts by surname, then first name — like a phone book. Click the heading to flip A→Z / Z→A.
  2. Only Name and City can be sorted. Addresses are free text and phone numbers come in mixed formats, so sorting them would look broken.
  3. City sorts by city, then by name. Z→A reverses the cities only; owners inside one city still read A→Z.
  4. 5, 10 or 20 owners per page (10 to start), with the total and arrows to move between pages.
  5. Search as you type: no Find Owner button, the list updates once you stop typing, back on page 1. Try "Pot".
  6. The screen remembers where you were: the page, sort and search travel in the address, so going back or refreshing returns here.

Accented names follow Romanian alphabet rules: Ș after S, Ț after T — so Șerban comes after Śliwiński. Today they would sink below Z.
